Rockheyday Updates Krum-C Spectral Dynamics Compressor to v2.5

14th September 2026 - KVR Audio News
    
Listen to audio version of this article
Sponsored by
0:00 / 0:45
Instaread

Rockheyday has released version 2.5 of the spectral dynamics compressor Krum-C, featuring performance and UI improvements following v2.0 which introduced a new licensing system.

New in v2.5:

  • Upgraded core graphics engine to JUCE 9 for enhanced UI rendering performance.
  • Added real-time Gain Reduction meter with calibrated reference markers.
  • Added preset bar with drop-down menu, next, previous, and save buttons.
  • Replaced Compact size mode with Large size mode.
  • Optimized under-the-hood mechanics for UI knobs and parameter snapping.
  • Improved spectrum visualizer calibration across high sample rates.

Pricing & Availability

Krum-C is available for Windows and macOS in VST3 and AU plugin formats for $19.99.
