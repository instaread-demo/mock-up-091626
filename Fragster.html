VALORANT introduces new Agent Mastery system with exclusive portraits and IDs

 John Parker 14. September 2026
Listen to audio version of this article

Instaread

VALORANT is getting a major progression overhaul with the introduction of Agent Mastery, a new system designed to track how much time and success players have with individual Agents.

The feature launches on September 22 with Patch 13.06 and introduces two separate progression paths: Act Levels and Lifetime Levels.

Players will also be able to unlock temporary Agent Portrait upgrades, earn permanent progression rewards and customize new Agent IDs with different visual modules and tracked statistics.

Agent Mastery arrives with Patch 13.06

The new system gives VALORANT players a way to demonstrate experience with a specific Agent beyond simply owning cosmetics or having a high account level.

Agent Mastery tracks progress individually for every Agent.

  • Agent Mastery launches on September 22
  • The system arrives with VALORANT Patch 13.06
  • Progress is divided into Act Levels and Lifetime Levels
  • Mastery Points are used to increase both progression tracks

The system is designed to reward players who consistently spend time on one Agent while also giving them reasons to revisit different characters.

Agent Mastery turns individual Agent experience into a visible progression system rather than something that exists only in a player’s match history.

Act Levels reset every Act

Act Levels form the seasonal side of Agent Mastery.

Each Agent has a separate Act Level that resets whenever a new VALORANT Act begins.

Players who reach a sufficiently high level during an Act can temporarily unlock an upgraded portrait for that Agent.

That portrait becomes visible during Agent Select, giving teammates and opponents a quick indication that the player has recently spent significant time on the character.

Progression type How it works
Act Levels Reset every Act
Portrait Upgrade Temporary reward tied to Act progress
Lifetime Levels Permanent Agent progression
Mastery Points Currency used to progress mastery
Agent ID Customizable Agent profile

Because the portrait upgrade is temporary, players will need to continue using the Agent in future Acts if they want to maintain that status.

Lifetime Levels track permanent progress

Lifetime Levels work differently.

Instead of resetting, this progression remains permanently attached to each Agent.

The system will absorb the existing Agent Gear reward tracks, meaning cosmetics previously connected to individual Agents will become part of Lifetime Mastery.

That includes items such as player cards, sprays, titles and weapon cosmetics tied to specific characters.

  • Lifetime Levels never reset
  • Existing Agent Gear is moving into this progression path
  • Previously unlocked rewards remain in player inventories
  • Players will need to use the relevant Agent to progress further

This changes how players approach Agent-specific cosmetics.

Previously, many rewards could simply be purchased with Kingdom Credits. Under the new system, progression becomes more closely connected to actually playing the Agent.

Existing Agent Gear will not disappear

Players who have already unlocked Agent Gear do not need to worry about losing their rewards.

Riot is preserving previously earned cosmetics when Agent Mastery goes live.

Kingdom Credits will also continue to play a role in redeeming Agent Gear once the system launches.

The important difference is that access to those reward tracks will now be connected to Lifetime Agent progression.

That gives older cosmetics a clearer place inside VALORANT’s broader progression system.

Mastery Points reward playtime and performance

Both Act Levels and Lifetime Levels progress through a new currency called Mastery Points.

Players earn Mastery Points by spending time in matches with an Agent.

Performance and match outcomes can provide additional bonuses, meaning strong games and victories should accelerate progression compared with simply accumulating match time.

This creates several ways to advance.

A player who regularly wins and performs well on an Agent should climb faster, but players can still make progress through consistent play even if every match is not exceptional.

The exact balance between playtime, performance and wins will be particularly important once the system launches.

Agent IDs offer another customization layer

Agent Mastery also introduces Agent IDs.

These act as customizable profiles centered around individual Agents.

Players can equip different modules including stances, backgrounds and tracked statistics to personalize how their Agent identity appears throughout the game.

This adds a new visual reward layer beyond standard weapon skins or player cards.

Agent IDs could become especially appealing to dedicated one-tricks who want their preferred Agent to be a visible part of their overall profile.

New system encourages players to specialize

VALORANT has traditionally rewarded broad account progression more than deep specialization with individual Agents.

Agent Mastery changes that approach.

A Jett main, for example, will now have specific progression that reflects how much they actually use Jett. The same applies to every other Agent in the roster.

That could encourage players to invest more time into mastering specific characters rather than constantly switching based on daily missions or cosmetic rewards.

At the same time, separate progression for every Agent creates an incentive for completion-focused players to work through the entire roster.

Assessment

Agent Mastery is a logical progression update for VALORANT.

The game has always placed enormous importance on Agent knowledge, but there has been relatively little permanent progression tied directly to individual characters.

Act Levels create a short-term seasonal goal, while Lifetime Levels provide a longer progression path that should continue across multiple years.

Agent IDs and Portrait Upgrades also give that progress a visible purpose.

The key question will be how quickly Mastery Points are earned. If progression feels too slow, the system could become another grind. If it moves too quickly, the prestige of higher mastery levels may disappear.

For players who already dedicate hundreds of matches to one Agent, however, the new system finally provides a structured way to show it.

Agent Mastery launches with VALORANT Patch 13.06 on September 22.
